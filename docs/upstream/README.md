# Upstream history

Pennant began as a fork of [lsukev/ootp-front-office](https://github.com/lsukev/ootp-front-office), created and
maintained by Kevin Ivy under the MIT license. This folder keeps the upstream project's own release notes and
forum announcement exactly as they were when the fork was made, so the origin of the codebase stays visible.

- `changelogs/CHANGELOG-<version>.txt` and `-bbcode.txt` — upstream's release notes, 0.9.6 through 0.27.2, in plain
  text and in the BBCode its forum posts used.
- `FORUM_POST.md`, `FORUM_POST_BBCODE.txt` — upstream's announcement post for its 0.4 release.

These describe **upstream's product** ("OOTP Front Office") and its version numbers. They are not Pennant's
history and they are not maintained: Pennant's own release history is [../../CHANGELOG.md](../../CHANGELOG.md),
and Pennant's version lineage starts fresh at 0.1.0 (see D-049 in [../DECISIONS.md](../DECISIONS.md)). Upstream
has since released well past 0.27.2 (its tags run to v0.40.1); none of that is in this repository.
